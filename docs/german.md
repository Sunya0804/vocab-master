# 독일어 누적 단어장

Goethe-Institut의 공식 A1·A2·B1 Wortliste PDF를 기반으로 만든 독일어–한국어 학습 패키지다. Goethe 독일어 시험은 CEFR A1–C2의 여섯 단계가 있다. 이 문서는 공식 어휘 목록을 확보한 A1–B1을 다룬다. 상위 단계의 선별 확장은 [B2·C1·C2 안내](german-advanced.md)를 참고한다.

| 패키지 | 누적 항목 | Day 수 |
| --- | ---: | ---: |
| `packages/german-a1.json` | 820 | 41 |
| `packages/german-a2.json` | 1,579 | 79 |
| `packages/german-b1.json` | 3,620 | 181 |

A2는 A1을, B1은 A1·A2를 포함한다. 공통 단어는 같은 5필드 데이터를 사용한다. 순서는 가장 이른 출처 단계 순이며, 그 안에서는 원문 추출 순서를 유지한다. 각 패키지의 학습 기록은 독립적이다.

## 자료와 범위

- [A1: Start Deutsch 1 공식 Wortliste](https://www.goethe.de/pro/relaunch/prf/de/A1_SD1_Wortliste_02.pdf): 알파벳 목록 9–27쪽, 주제별 어휘 6–8쪽.
- [A2 공식 Wortliste](https://www.goethe.de/pro/relaunch/prf/de/Goethe-Zertifikat_A2_Wortliste.pdf): 알파벳 목록 8–31쪽, 주제별 어휘 5–7쪽. 확인본 표기 `A2_Wortliste_04_050526`.
- [B1 공식 Wortliste](https://www.goethe.de/pro/relaunch/prf/de/Goethe-Zertifikat_B1_Wortliste.pdf): 알파벳 목록 16–102쪽, 주제별 어휘 8–15쪽.

4,846개 알파벳 추출 그룹과 866개 주제별 참조를 검토했다. 명확한 옆 예문 열의 한 글자 조각 1건은 제외했다. 성별 파생어, 지역·철자 변형, 성이 다른 명사, 활용·결합 어간을 별도 카드로 구분한다. 출판사의 ‘어휘 단위’와 앱의 카드 수를 같은 수치로 해석하지 않는다. 날짜·시각·가격을 무한히 조합하여 카드 수를 늘리지는 않는다.

공식 알파벳 목록에서 빠진 기본 대명사 `du`, `mich`, `mir`, `uns`, `euch`, `ihnen / Ihnen` 여섯 항목은 편집 보강으로 명시했다. PDF에서 직접 가져왔다고 표시하지 않는다. B2·C1·C2는 별도의 누적 확장 패키지로 제공하며, 공식 필수어휘 전체 목록으로 취급하지 않는다.

## 데이터 사용

기존 5칸 배열을 그대로 사용한다.

```json
["das Museum", "박물관", "명", "Das Museum zeigt eine Ausstellung über alte Berufe.", "박물관이 옛 직업에 관한 전시회를 연다."]
```

- 패키지의 `lang`은 `de-DE`, `languageName`은 `독일어`다.
- 기존 품사 코드에 독일어 관사 `관`, 수사 `수`를 추가했다. 복합 품사는 `/`로 연결한다.
- 한국어 뜻·예문 해석은 새로 작성했다. 독일어 예문도 출판사 문장을 옮기지 않고 작성했다. 명사는 의미 분야에 맞춘 학습 문형과 개별 예문을 함께 사용한다. 모든 예문은 15단어 이내다.
- 명사 성은 표제어에 포함한다. `wordInfo`는 표제어를 키로 사용하며 성·복수형·복수 전용 여부·일부 단수 용법·재귀 용법·지역·사용 설명을 담는다.
- `wordInfo.cefr`는 가장 이른 출처 목록의 단계다. 단어 자체의 난이도를 별도로 공인한 값은 아니다.
- 복수형을 확인하지 못한 명사는 `pluralNote`에 ‘자료에 복수형 미표기’를 넣었다. 복수형이 존재하지 않는다는 뜻이 아니다. 일부 기본 명사의 복수형은 편집 보강으로 표시했다.
- `Banken`(은행들)과 `Bänke`(벤치들)처럼 뜻에 따라 복수형이 달라지는 경우는 사용 설명을 제공한다.
- 문법 정보는 뜻과 분리하여 역방향 퀴즈의 정답을 노출하지 않는다. 뜻 가리기와 카드 앞면에서도 숨긴다.

`Sie/sie`, 언어명 `Deutsch`와 형용사 `deutsch`는 대소문자가 의미를 갖기 때문에 한 카드에서 두 용법을 표시한다. 어간은 단독 단어처럼 가르치지 않고 결합·활용 항목이라고 표시한다. 지역 표현에는 가능한 경우 독일(D)·오스트리아(A)·스위스(CH)를 표시한다.

## 추적과 검증

`docs/german-sources.json`에 PDF URL·버전·SHA-256, 전체 표제어별 출처 페이지, 추출 그룹과 카드의 대응, 주제별 참조, 정규화 교정을 저장했다. `wordIndices`는 `german-b1.json`의 0부터 시작하는 인덱스다. PDF 예문 본문은 기록하지 않는다.

원문의 `der Hinweise`·`die Kursleiter` 오기, 추출 과정의 붙은 표제어, 오래된 `Ketschup`·`leid tun` 표기를 교정했다. 명사 복수형은 완전한 표기를 축약 어미보다 우선한다. 독일어 철자 사전 대조 결과의 미인식 항목은 지역 표현·약어·어간·유효한 변형인지 별도로 검토했다. 철자 검사는 문법·번역에 대한 원어민 감수를 대신하지 않는다.

```powershell
node test/german.test.js
node test/core.test.js
node test/toeic.test.js
node test/questions.test.js
```

앱은 단어장별 언어를 카드·단어 목록·듣기·오답노트에 전달한다. 독일어는 기기의 독일어 TTS 음성을 사용하며 음성 설치 여부와 실제 발음 품질은 기기에 따른다. 영어 단어장과 토익 문제의 음성 언어는 영어를 유지한다.

2026-11-10 검증: 독일어 데이터·UI 함수 6개, Core 47개, TOEIC 데이터 6개, 시험 문항 8개로 총 67개 검사를 통과했다. 앱·서비스 워커의 문법 검사와 `git diff --check`도 통과했다. HTTP에서 세 독일어 패키지의 개수 및 앱 파일의 200 응답을 확인했다. 내장 브라우저가 미등록 로컬 HTTP 원본을 차단하여 실제 화면의 시각 검증은 수행하지 못했다. 독일어·한국어 발음 큐의 언어 선택은 실제 UI 함수의 모의 음성 엔진 테스트로 확인했으며, 실제 음성을 청취한 검증은 아니다.
