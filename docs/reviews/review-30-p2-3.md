## 권장 4묶음

### R1. p2-3-008 — 사건 처리 문맥의 mediation 번역

- 정답: “They contain cases awaiting mediation.”
- 현재 번역: “중재를 기다리는 사건들이 들어 있다는 뜻이에요.”
- 이 사건 처리 문맥에서는 mediation을 **조정**으로 옮기면 arbitration의 중재와 더 명확히 구분된다.
- 권장 번역: **“조정을 기다리는 사건들이 들어 있다는 뜻이에요.”**
- 영어 정답은 그대로 유효하며, 다른 보기의 장소·커튼 선호와 구별되므로 키 오류나 복수 정답 문제는 아니다.

### R2. p2-3-035 — 야간 운전의 목적을 전기요금 절약으로 명확히

- 발화: “Let's run the laundry machines overnight to save electricity.”
- 정답 A: “Their spin cycles wake the upstairs tenants.”
- 운전 시각을 밤으로 옮긴다는 사실만으로 전력 사용량 자체가 줄어든다는 근거는 발화에 없다. 의도한 목적이 야간 요금 활용이라면 그 조건을 직접 써 주는 편이 자연스럽다.
- 권장 발화: **“Let's run the laundry machines overnight to use the cheaper rate.”**
- 번역 예: **“더 저렴한 요금을 적용받도록 세탁기를 밤에 돌려요.”**
- 제안이 실제로 유리한지와 별개로 소음 때문에 반대하는 A는 현재도 자연스럽고 유일하다. 따라서 필수가 아닌 표현 개선이다. 일반적으로 모든 사업장에 싼 야간 요금이 있다는 뜻이 아니라, 새 발화에서 해당 상황의 조건을 명시하는 수정안이다.

### R3. p2-3-021 ↔ m-p2-2-14 — 균열 물건의 유지·교체 판단이 가까움

| 신규 | 기존 모의 | 공통점과 차이 |
|---|---|---|
| “Should we keep the café's marble countertop or replace it?” → “The cracks extend all the way through.” | “Do we repair the cracked mold or discard it?” → “The engineer says another repair would be unsafe.” | 균열이 있는 물건을 유지/수리할지 교체/폐기할지 묻고 상태·안전 사정으로 후자를 암시한다. 물건과 제시 근거는 다르다. |

완전한 문장 복제는 아니며, 유지보수 선택은 Part 2에서 일반적인 상황이다. 다만 신규 소재의 폭을 넓히려면 하나를 상태·안전 판단이 아닌 다른 선택으로 바꾸는 것을 권장한다.

예를 들어 신규 021을 다음 방향으로 바꿀 수 있다.
- 발화: “Should the café's countertop have a glossy or matte finish?”
- A: “The overhead lights already create a lot of glare.”
- 광택/무광 선택에서 눈부심이라는 사정으로 무광을 암시하도록 한다. 현재 choice·난이도 3·정답 A를 유지할 수 있는 방향이다.
- 적용한다면 한국어·해설을 바꾸고 B/C까지 다시 대입해야 한다. 이번 보고서에서는 적용하지 않았다.

## 유형·trap·반복·번역

### 유형과 간접 응답

- wh 22, yesno 8, negative-tag 4, choice 4, request 6, statement 6. 200문항 기본 명세의 수량을 50문항 파일에 그대로 강제하지 않았다.

### trap

허용 목록 밖의 값은 없다. 두 오답에 대응하는 2개 태그가 모두 있으며, 같은 함정이 두 오답에 쓰여 repeat-word가 반복된 배열 자체는 오류가 아니다. 표제어·파생형·관련어의 경계가 겹칠 수 있으므로 태그 이름 하나만으로 정답의 유일성을 판정하지 않았다.

- 007의 square/panel, 018의 margin, 029의 posting/posted, 036의 feet, 046의 meter는 다른 의미의 단어 반복 함정이다.
- 012의 valve/values, 030의 staple/stable, 044의 natural/Naturally는 텍스트상 유사 소리·형태의 연상이다. 044는 같은 어근이므로 repeat-word로도 설명할 수 있으나 similar-sound를 필수 오류로 보지 않았다. 실제 음성의 유사성은 듣지 않았다.
- 010의 탱크 용량과 018의 감사 기간은 이유/내용 대신 다른 정보를 답하는 wh-mismatch로 볼 수 있다.
- 035 C의 청구서 번호 **위치**는 전기요금 확인 경로를 알려 주는 말이 아니다. 21차의 정보 출처 안내 오답과 구분했다.

### 반복

유형은 섞여 있어 기존 200문항의 긴 유형 블록을 그대로 반복하지 않는다. 정답 기호도 최대 2연속이다.

011·026·032의 인물/대상/보너스 종류 확인은 같은 넓은 기능의 되묻기지만, 간접 응답 21개 중 3개이고 발문 대상도 다르다. 이 수만으로 반복 틀 위반을 필수 판정하지 않았다. “시기 질문 → 선행 승인 대기”가 여러 문항에 연속되는 이전 21차의 집중도 이번에는 나타나지 않는다. 다만 오답의 반복적인 배제 방식은 R4로 남겼다.
