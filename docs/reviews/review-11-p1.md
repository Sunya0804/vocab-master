## 6. 형식·파일 검증

- 60문항, 고유 ID 60개, image 경로 60개, 누락 이미지 0개.
- 난이도: 1/2/3 = 15/27/18.
- 사진 유형: single/group/object = 24/18/18.
- 정답: A/B/C/D = 15/15/15/15. 같은 정답 4연속 없음.
- 보기·번역 각 4개, 정답 인덱스 유효, 모든 영어 보기 4–12단어.
- 인물 사진에서 배경 사물이 정답인 문항: 016, 019, 040, 041, 042 — 5개.
- 이미지: 모두 WebP, 1024×768, 4:3. 최대 **119,522 bytes** (119.522 KB / 약 116.72 KiB), 120 KB 이하.
- 모두 시각적으로 흑백. 디코딩 RGB 채널 간 최대 차이는 255단계 중 **1**이므로, 완전한 채널 바이트 일치 여부만으로 컬러 이미지라고 판정하지 않았다.
- 기계 검증은 파일 형식·개수·범위를 확인한 것이며, 정답 유일성과 사진 품질은 위 개별 육안 검토 결과다.

공유 루트에서 재현 가능한 구조 검증 명령:

```powershell
node -e "const fs=require('fs');const a=JSON.parse(fs.readFileSync('questions/toeic-part1.json','utf8')).questions;const c=k=>a.reduce((m,q)=>(m[q[k]]=(m[q[k]]||0)+1,m),{});console.log('items',a.length,'diff',c('difficulty'),'photoType',c('photoType'),'answer',c('answer'),'missing',a.filter(q=>!fs.existsSync(q.image)).length,'maxBytes',Math.max(...a.map(q=>fs.statSync(q.image).size)),'bad',a.filter(q=>q.choices.length!==4||q.ko.choices.length!==4||q.answer<0||q.answer>3||q.choices.some(t=>t.split(/\s+/).length<4||t.split(/\s+/).length>12)).map(q=>q.id))"
```

명령 출력:

```text
items 60 diff { '1': 15, '2': 27, '3': 18 } photoType { single: 24, group: 18, object: 18 } answer { '0': 15, '1': 15, '2': 15, '3': 15 } missing 0 maxBytes 119522 bad []
```
