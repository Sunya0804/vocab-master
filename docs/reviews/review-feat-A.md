## 직접 수정

1. **기존 단어 재학습 누락**: 이전에는 처음 일정을 만든 단어만 `learned` 활동을 기록하여, 이미 공부한 단어의 재학습일은 연속일에서 빠졌다. 모든 학습 답변에 `studied` 활동을 기록하고, 처음 접한 단어와 만기 복습은 각각 `learned`/`reviewed`에 구분해 집계한다. 일반 카드·퀴즈·빈칸에서 만기 단어를 답해도 복습 실적으로 반영한다. 전용 복습 화면의 중복 집계는 제거했다.
2. **긴 연속 학습일 손실**: 60일 전 기록을 지워 62일 이상 연속 기록이 잘렸다. 과거 날짜 기록을 보존하며, 내용이 0인 빈 날짜는 학습일로 세지 않는다. 100일 연속 검사 추가.
3. **새 상태 필드 검증**: 정규식만 통과하는 2월 30일, 윤년이 아닌 2월 29일, 13월 등을 거부한다. 복습·별표의 키가 `Core.wordId(pkg,en)`과 일치하고 pkg/en이 공백이 아닌지도 확인한다. 활동 카운터는 음수가 아닌 안전한 정수여야 한다.
4. **백업 복원 검증**: 새 필드가 잘못됐을 때 조용히 버리고 복원을 완료하던 동작을 수정했다. 확인 대화상자와 저장 전에 거부하고 기존 상태를 보존한다. 새 필드가 없는 이전 백업은 계속 복원·일정 분산한다. 정상 새 백업은 일정·별표·목표·활동을 보존한다.
5. **여러 탭 저장**: storage 이벤트가 오기 전에 오래된 탭이 전체 상태를 저장하면 다른 탭의 별표·일정·학습 기록을 지웠다. 마지막으로 읽은 상태와 현재 탭의 차이만 최신 저장본에 반영한다. 별표 삭제도 보존하고 날짜별 활동 증가는 합산한다. 복원·초기화는 명시적으로 전체 교체하므로 의도한 삭제가 병합에 의해 되살아나지 않는다.
6. **레벨 필터와 이어서 학습**: 홈의 오늘 카드가 전체 단어장의 첫 미완료 Day만 추천하던 문제를 수정했다. 선택 레벨의 첫 미완료 Day를 추천하며, 그 레벨을 모두 마쳤을 때도 같은 레벨의 첫 Day로 돌아간다.
7. **복습 대상 유효성·지연 로드**: 존재하지 않는 표제어는 만기 개수에서 제외한다. 처음 50개 저장 항목의 패키지만 로드하면 그 항목이 오래된 표제어일 때 뒤의 정상 단어가 가려질 수 있어, 만기 대상의 패키지를 로드한 뒤 정상 단어를 최대 50개 고른다.
8. **별표와 목록 배치**: 별표 상태에 따라 접근성 이름을 담기/빼기로 갱신한다. 단어 목록의 발음·별표·알아요 세 컨트롤이 각각 들어가도록 그리드 열을 추가했다. 이 CSS 변경의 실제 폭별 시각 확인은 위 미완료 항목에 포함된다.
9. 새 코어 API가 캐시에 없는 조합도 시작 시 감지하도록 준비 검사에 추가했고, 기존 알아요 항목 중 빈 표제어 키는 일정 분산에서 제외했다.

## 남은 필수 / 권장

- 필수: 로컬 개발 주소를 Dochi에서 허용하거나 외부 헤드리스 브라우저 검사를 명시적으로 허용한 후, 위 3화면을 360/900/1280px × 라이트/다크로 확인한다. 화면상 결함이 있으면 수정 후 테스트와 판정을 갱신한다.
- 권장: 현재 변경 병합은 서로 다른 기록을 오래된 탭이 지우는 상황을 방지한다. localStorage의 읽기→쓰기 자체는 트랜잭션이 아니므로, 두 탭이 정확히 동시에 같은 단어를 수정하는 경우까지 충돌 없는 저장을 보장하지 않는다. 강한 동시성 보장이 필요하면 IndexedDB 트랜잭션 또는 탭 간 직렬화를 검토한다.
- 권장: 오늘 카드의 새 단어 목표는 첫 일정 생성 수를 기준으로 하며, 기존 단어 재학습은 연속일에는 반영되지만 새 단어 실적을 늘리지 않는다. 이 기준은 화면 안내와 함께 유지하는 것이 좋다.
