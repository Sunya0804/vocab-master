## 1. p6-2.json

### 필수
1. **012-Q4 해설**(직접 확인): "deadline은 바뀌지 않는 대상으로 언급된 입찰 금액과 다르다"라고 하지만, 지문에서 고정되는 것은 reserve(최저 매각가)다. → "deadline은 지문에 나오지 않으며, 입찰이 시작된 뒤 고정되는 것은 최저 매각가라는 기준 금액이다."

### 권장
1. **tense 국면 동사 오답 9/14**(004·005·006·009·010·011·012·015·016).
   - 거의 같은 짝: 006=010, 005=016, 004=011.
   - 015 will have completed / will be starting은 18차 금지 짝이다.
   - → 010·011·015·016의 결정적 오답을 일반 시제로 바꾼다(예: 016 wrote / will write / has written / was writing).
2. **빈칸 문장 안의 단서:** 010-Q4 "; each check will begin…", 009-Q1 "before the new design…", 015-Q2 "By that run", 016-Q1 "when I approached". → 앞뒤 문장으로 옮긴다.
3. **금지된 단서:** 002-Q1 화면 표시("displayed times now"), 014-Q2 완료 기록("can now see photographs of the finished installations"). → 사건 단서나 현재와 이어지는 단서로 바꾼다.
4. **012-Q1:** 둘째 미래형 "will have stopped displaying"이 뜻으로 바로 지워진다(14차 취지). → 실제로 경쟁하는 미래형으로 바꾼다.
5. **관찰 방문 단서 4지문**(004·005·011·016). → 011·016의 단서를 일정이나 결과로 바꾼다.
6. **연결어:** 001과 013의 세트가 같다. 인과 정답이 6/8이다. → 013 세트를 {For this reason, Otherwise, In addition, Even so}로 바꾸고, 2문항은 Instead나 In addition이 정답이 되게 한다.
7. **단어 반복:** 010-Q3(정답만 model), 001-Q4(정답 "that pause"). → 오답에도 model을 넣고, 001은 "between cups"로 바꾼다.
8. **006과 013의 뼈대가 같다**(실연 관람 + 안전 경계 + 인과 + 접근 시점).
9. **pos 틀:** 003·010·013이 모두 "관사 + 형용사 + 명사"다.
10. **010 사실 충돌:** 3문단은 이미 하는 서비스처럼 쓰는데 4문단은 "launches next month"다. → 3문단을 will provide로 바꾼다.
11. **002-Q2 정답** "…is temporarily different" → "…has temporarily changed."
12. **011-Q1 해설 ko:** "In contrast는 대조가 아니며" → "앞뒤가 대조 관계가 아니므로…".
13. **008·015:** 스프레드시트 소재와 날짜(11/6)가 겹친다. 008은 m-p6-1-02와 뼈대가 같다.
14. **정답 위치:** 12/16지문이 네 기호를 한 번씩 쓴다. → 4~5지문은 다시 배열한다.

참고:
- 007·014는 pronoun 세트와 정답 them이 같다.
- 006 public → staff, 011 permission → indication.
- 014-Q2 ko "완성해 오고 있었다".
- 005 ↔ p6-1-005: 호텔 천 견본 소재가 일부 겹친다.
- 004·006은 비회사 소재다.

## 2. p7-3.json — 배포 가능
- 58문항 모두 정답이 하나다. insertion 4문항(016·017·019·020)도 자리가 하나뿐이다. 계산(009 80, 013 750)도 맞다.

### 권장
1. **채팅·문자 흐름 4세트(17차 규칙 위반):** 003·007·015·018이 "과한 제안 → 비유 인용으로 제지 → 대안"이다. 015·018은 인용 바로 다음 줄이 뜻을 풀어 준다. → 007·018의 의도를 동의·놀람·확인 기능으로 바꾼다.
2. **기사 3세트 같은 전개(014·016·019).** 016과 019는 문장까지 거의 같다. → 019를 공지나 절차 안내형으로 바꾼다.
3. **광고 3세트 같은 뼈대(004·008·012).** "별도 처리·추가 요금" 문장이 5세트에 있다. → 008이나 012를 바꾼다.
4. **"does not / do not / rather than" 25회 이상.** 정답 근거로도 반복된다. → 세트당 1회 이하로 줄인다.
5. **소재:** 004(수족관, 아래 4절), 008 ↔ p7-4-004 ↔ 001(견본·교정 승인), 014 ↔ m-p7-1-14(조명 아래 표찰 구별). → 008과 014를 바꾼다.
6. **정답 위치:** 001~008이 AC·BD·CA·DB를 두 번 반복한다. 3문항 세트도 CAD·BCA가 반복된다. → 섞는다.
7. **Q1 오답이 상식만으로 지워진다:** 004-Q1 C, 006-Q1 C·D, 008-Q1 A·B, 020-Q1 C·D.
8. **정답이 지문을 거의 그대로 옮겼다:** 011-Q3, 012-Q3, 019-Q3, NOT 문항 002-Q2 D, 010-Q2 C.

참고:
- 012-Q3: 오답 둘이 같은 근거로 지워진다.
- 015-Q2 C가 약하다.
- 017-Q1·Q2가 같은 사실을 묻는다.

## 3. p7-4.json — 배포 가능

### 권장

## 5. 작성 지시에 대한 제안
- 새 파일에 10~19차에 걸쳐 고친 공식이 처음부터 들어가 있다. 다음 작성 지시에 넣기를 권한다.
  1. 세트 안 정답 위치가 순열이 되지 않게 섞는다.
  2. tense 결정 오답의 종류를 섞는다(국면 동사만 쓰지 않는다).
  3. 세트마다 crossRef 위치와 지문 조합을 다르게 한다.
  4. 같은 배치의 다른 작성자 파일 제목과 첫 문장을 대조한다.

## 확인하지 못한 것
- 한국어 번역은 뜻이 바뀌는 오류와 핵심 수치만 대조했다.
- 소재 겹침은 제목·첫 문장·핵심어 검색 위주로 확인했다.
- 정답 위치 비율은 자동 점검을 통과했다는 전제로, 세트 안 패턴만 봤다.
