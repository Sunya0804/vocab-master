## 기능
- Day 화면(`renderDay`)의 퀴즈 버튼 옆에 "예문 빈칸" 시작 버튼 추가. 기존 세션 체계(`startSession`, `#/...` 라우트, 결과 화면, 오답노트 기록 `Core.recordAnswer`, missed)를 재사용. 오답노트·복습에서 시작하는 퀴즈가 있으면 거기에도 같은 방식으로 붙일 수 있으면 붙인다(복잡하면 Day만).
- 문제 화면:
  1. 예문(`word[3]`)에서 표제어에 해당하는 부분을 빈칸으로 바꿔 보여 줌. 빈칸은 글자 수만큼의 밑줄(스크린리더용 "빈칸 N글자" sr-only).
  2. 그 아래 예문 뜻(`word[4]`, exKo)을 보여 줌. 단어 뜻(`word[1]`)은 처음엔 숨김(채점 후 공개).
  3. 입력칸(자동 대문자·자동 수정 끔: `autocapitalize="off" autocorrect="off" spellcheck="false"`, `lang`=단어장 언어) + "확인" 버튼, Enter로 제출.
  4. "힌트 보기" 버튼: 1번 누르면 첫 글자, 2번 누르면 첫 두 글자를 빈칸 자리에 보여 줌(그 이상은 없음, 버튼 비활성). 힌트 사용 횟수는 세션에 기록하고 결과 화면에 "힌트 사용 N문제" 표시.
  5. 채점: 맞으면 정답 표시, 틀리면 정답 철자와 내가 쓴 답을 함께 보여 줌(색만으로 구분하지 않음). 예문 전체·단어 뜻·발음 버튼 공개 → "다음".
- 빈칸 대상 찾기(core.js 순수 함수로, 테스트 추가):
  - 기존 `highlightedExample`의 어간 매칭 규칙을 재사용/추출해서 같은 규칙으로 찾는다(활용형 "arranged", 독일어 "fährt"도 예문에 실제로 쓰인 형태가 정답). 독일어 관사 der/die/das/sich는 빈칸 대상에서 제외(기존 규칙 그대로).
  - 표제어가 여러 단어(구동사·숙어)면 매칭된 단어들을 각각 빈칸, 정답은 그 단어들을 순서대로 공백으로 이은 것.
  - 예문이 없거나 매칭 실패한 단어는 문제에서 빠짐. Day의 문제 가능한 단어가 0이면 버튼 비활성 + 이유 표시.
- 정답 비교: 앞뒤 공백·대소문자 무시, 연속 공백 하나로, 따옴표 ’ ' 같게. 독일어는 ä/ae, ö/oe, ü/ue, ß/ss도 정답 인정. 그 외 철자 차이는 오답.
- 기록: 맞음/틀림을 기존 퀴즈와 같은 방식으로 기록(힌트 써서 맞혀도 맞음). 새 저장 키 만들지 말 것.
