사용자: "실전 모의고사를 만들되, 원래 있던 문제를 조합하지 말고 새로운 문제를 만들어줘." / "실전 모의고사는 5회 분량을 만들자"
문제는 작성자들이 `docs/tasks/mock-spec.md`대로 쓰는 중. 시험 구성·점수 근거는 `docs/research/toeic-p1-p6-p7.md` 4장.
공유 main 최신(95ff7fd)으로 맞추고 시작. 데이터 파일 수정·커밋 금지.

## 데이터 (총괄이 조립)
`questions/mock/mock-1.json` ~ `mock-5.json` = `{"version":1,"test":1,"parts":{"1":[문항],"2":[문항],"3":[세트],"4":[세트],"5":[문항],"6":[세트],"7":[세트]}}`. 각 파트 항목 형식은 기존 파트 파일과 같다(Part 1 image 경로는 `images/mock/...`). 개발용 임시 데이터는 기존 파트 파일에서 뽑아 **test/fixtures/** 등 배포되지 않는 곳에 만든다(questions/mock에는 두지 않는다). 파일이 없으면 모의고사 카드는 "준비 중".

## 화면
- 문제 홈에 "실전 모의고사" 영역: 1~5회 카드(응시 기록 있으면 최근 예상 점수·날짜).
- **LC(Part 1~4):** 실제 시험처럼 음성이 끊김 없이 이어서 재생(문항마다 다시 듣기 없음, 다만 앱이니 "전체 일시정지" 하나는 둠). 문항 사이 간격은 실제처럼 몇 초. Part 1 사진·Part 3·4 그래픽은 시험지처럼 표시. 음성이 안 되면 기존 파트 화면의 대본 표시 대체 동작.
- **RC(Part 5~7):** 75분 타이머(남은 시간 표시, 0이면 자동 제출). 문항 사이 자유 이동. Part 6·7은 기존 2단 표시 재사용.
- **답안지:** 1~200번 표(OMR처럼 A~D 표시, Part 2는 A~C). 아무 때나 열어서 답 확인·이동. 안 푼 문항 표시.
- **결과:** LC/RC 맞힌 수, 예상 점수(연구 문서 4-4 근사표 중간값 선형 보간, "근사·공식 환산표 비공개" 명시), 파트별 정답률, 틀린 문항만 보기 → 해설·번역·대본. 응시 기록 저장(회차별 여러 번), 백업·복원에 포함.
- 중간에 나가도 이어 풀기(진행 상태 저장).

## 검증
node test/*.test.js + 모의고사 데이터 형식 테스트(회차마다 파트별 수량 = 6/25/13세트/10세트/30/4세트/15세트, 문항 총 200, 정답 범위, Part 1 이미지 존재) — 파일이 없으면 건너뜀.
