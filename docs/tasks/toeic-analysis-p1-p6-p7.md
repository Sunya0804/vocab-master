# 실제 토익 분석: Part 1·6·7 + 실전 구성 (리서치)

사용자: "파트 1을 포함해서 6, 7도 만들어 줘. 실제 토익 문제를 분석해서, 난이도와 유형 및 그림이 최대한 유사하도록 구현해줘. 이후 실전 모의고사를 만들되, 원래 있던 문제를 조합하지 말고 새로운 문제를 만들어줘."
이 문서는 명세(총괄이 씀)의 근거다. **코드·데이터 수정 금지.** 결과는 `docs/research/toeic-p1-p6-p7.md`에 쓴다. 지문·문장·그림을 복사해 오지 않는다(형식·비율·패턴만 기술, 인용은 한 줄 이내 예시로만).

## 조사 대상
ETS 공식 샘플·응시 안내(공개 자료), 공개된 신토익(2016 개정) 형식 설명, 신뢰할 만한 출판사·학원 분석 글(유형 비율 통계). 출처 URL을 항목마다 적는다.

## 정리할 것
1. **Part 1 (6문항)**: 사진 종류 비율(1인 동작 / 2인 이상 / 사물·풍경), 장소 분포(사무실, 공사장, 상점, 야외 등), 오답 함정 유형(동작 혼동, 사물 오인, 상태 vs 진행 수동태 "is being", 사진에 없는 단어, 유사 발음), 문장 시제·구조 패턴, 난이도별 특징. 사진 자체의 시각적 특징(실사 사진, 흑백/컬러, 구도, 인물 수·거리, 배경 복잡도, 텍스트 거의 없음 등) → 우리가 그림을 만들 때 쓸 체크리스트.
2. **Part 6 (4지문 × 4문항)**: 지문 종류(이메일, 공지, 기사, 광고, 메모 등) 비율, 길이(단어 수), 문항 유형(어휘, 문법, 접속부사, 문장 삽입) 비율, 문장 삽입 문항 위치, 시제·문맥 의존 문항 비율.
3. **Part 7 (54문항)**: 단일 지문 세트 수·문항 수 분포(2/3/4문항 세트), 이중 2세트·삼중 3세트, 지문 종류(문자 대화·온라인 채팅, 양식·표, 광고, 기사, 이메일, 웹페이지 등) 비율, 문항 유형(주제·세부·추론·NOT/TRUE·동의어·의도 파악·문장 위치) 비율, 지문 길이, 연계 문항(두 지문을 함께 봐야 하는 문항) 비율.
4. **실전 1회 구성**: LC 100(45분)·RC 100(75분), 파트별 문항 수, 난이도 곡선(파트 안에서 뒤로 갈수록 어려워지는지), 정답 위치 분포, 점수 환산(공식 환산표는 비공개 → 공개된 근사 방식 조사, 근사임을 명시).
5. **우리 앱 기존 Part 2~5와의 차이**: docs/tasks/exam-lc-spec.md, questions/toeic-part5.json 등을 읽고, 실전 모의고사용으로 보완할 점(난이도 비율, 유형 비율)을 짧게.
