# 주제별 학습 2차: 수능·TEPS 단어장에 주제 추가 (Claude 작업자)

사용자: "day별로 단어를 학습할뿐만 아니라, 특정 상황이나 장소 등 주제를 정해서 그에 맞게 단어를 분류해서 볼 수 있게도 해주면 좋을 것 같아." TOEIC은 커밋 `5e27de0`에서 끝났다. 같은 방식으로 `packages/suneung.json`(3000)과 `packages/teps.json`(2000)에 `topics`를 넣는다.

## 데이터 형식 (TOEIC과 같음)
- 패키지 최상위에 `"topics": [{"name": "학교·교육", "words": ["headword", ...]}, ...]`. 한 항목 최대 20단어, 긴 주제는 같은 `name`으로 여러 항목에 나눈다(화면이 "학교·교육 1, 2…"로 번호를 붙인다). 순서는 단어장의 원래 순서.
- 단어는 `words`의 headword(0번 필드)를 **글자 그대로** 쓴다. 한 단어는 최대 한 주제. "important, however"처럼 어디에나 쓰이는 단어는 넣지 않는다(절반쯤 빠지는 것이 정상).
- 주제 목록(15~20개)은 단어장 성격에 맞게 정한다. 수능·TEPS는 일상·학교·감정·자연·과학·사회·경제·건강·여행·음식·문화·예술·직업·기술·환경·정치·법 같은 일반 주제가 맞다.
- 파일 쓰기: `scripts/merge-senses.js`의 `formatPackage(pkg, 기존 텍스트)`로 직렬화해 기존 서식(수능·TEPS는 한 단어 한 줄)을 유지한다. `test/senses.test.js`가 서식을 검사한다.

## 분류 방법
- 단어 목록을 여러 묶음으로 나눠 서브에이전트로 분류해도 된다. **번호가 아니라 headword 문자열로 답하게** 하고(번호로 받으면 어긋났다), 결과를 실제 headword와 대조해 없는 단어는 버린다.
- 주제마다 표본 15개쯤 직접 보고 엉뚱한 분류를 고친다.
