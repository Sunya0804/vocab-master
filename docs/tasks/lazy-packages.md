# UI 14차: 단어장 필요할 때만 불러오기 (UI 워커)

사용자: "다른 워커의 작업을 대기하는 동안, 어떤 점이 개선이 필요한지, ui는 더 좋게 할 방법이 없을지 검토하고 수정해."
문제: 시작할 때 `app.js` init이 packages/index.json의 9개 단어장(약 7MB, 독일어 6개는 누적이라 대부분 중복)을 전부 받은 뒤에야 첫 화면을 그린다. 휴대폰 데이터·느린 망에서 첫 화면이 늦다.

## 시작 전
공유 폴더 최신 파일을 작업 폴더로 가져온다(방금 UI 정리·독일어 빈칸이 들어감). 데이터(packages/, questions/) 수정 금지, 커밋 금지.

## 할 일
- 첫 화면에 필요한 것만 먼저: **선택된 단어장 1개**를 먼저 받아 그리고 나머지는 필요할 때 받는다. 언어 전환·단어장 선택 목록에 이름이 필요하면 최소 방법을 고른다(예: index.json을 `[{file,id,name,lang,languageName}]`로 바꾸는 게 가장 단순하면 그렇게 하되 테스트·sw.js도 맞춤 — 이 경우만 index.json 수정 허용, 단어장 파일과 이름이 어긋나지 않게 테스트 추가).
- 오답노트·전체 복습처럼 여러 단어장 단어가 필요한 화면은 그 화면에 들어갈 때 필요한 단어장만 받는다. 받는 중엔 기존 "불러오는 중" 표시.
- 오프라인: 서비스 워커 캐시는 지금처럼 동작해야 함(한 번 연 단어장은 오프라인에서도 열림). 설치 때 미리 캐시하는 범위는 지금 sw.js 동작 유지.
- 기록·백업 복원·가져온 단어장(custom)은 영향 없어야 함.

## 검증
- node test/*.test.js 전부 통과(토익 테스트 1개는 데이터 정리 워커 작업 때문에 실패할 수 있음 — 이번 변경과 무관한지 확인).
- Playwright: 첫 화면까지 받은 바이트·시간 전/후 비교(네트워크를 3G 정도로 제한), 언어 전환·단어장 변경·오답노트·문제 화면 동작, 콘솔 에러 0, 오프라인 재방문.
- sw.js CACHE_VERSION 올림.
