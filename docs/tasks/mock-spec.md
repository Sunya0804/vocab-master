# 실전 모의고사 5회 명세 + 작성 분담

사용자: "이후 실전 모의고사를 만들되, 원래 있던 문제를 조합하지 말고 새로운 문제를 만들어줘." / "실전 모의고사는 5회 분량을 만들자"
- 1회 = 실제 토익과 같은 200문항(LC 100 / RC 100). **모두 새로 쓴다.** 기존 `questions/toeic-part1~7.json`의 문항·지문·사진·소재를 재사용·변형하지 않는다(쓰기 전 기존 파일 제목·첫 문장을 훑어 겹침 확인).
- 형식은 파트별 기존 명세 그대로: Part 2·5 `docs/tasks/exam-spec.md`, Part 3·4 `docs/tasks/exam-lc-spec.md`, Part 1·6·7 `docs/tasks/exam-p167-spec.md`(**끝의 "검토에서 나온 규칙" 필수 적용**). 실제 시험 구성 근거는 `docs/research/toeic-p1-p6-p7.md` 4·5장.
- 각 항목에 `"test": 1~5`를 붙인다. 회차마다 아래 1회 구성을 정확히 채운다. 회차 간 난이도는 비슷하게(각 회 25/45/30).

## 1회 구성(회차마다)
| 파트 | 수량 | 순서·구성 규칙 |
|---|---|---|
| 1 | 6문항 | single 2~3 → group 1~2 → object 1~2 순(사람 사진 앞, 사물 뒤) |
| 2 | 25문항 | wh 11, yesno 4, 부정·부가 2, 선택 2, 요청 3, 평서 3. 간접 응답 정답 35~45% |
| 3 | 13세트(39문항) | 3인 대화 1~2세트, 의도 문항 2개, 그래픽 3세트는 **마지막 3세트** |
| 4 | 10세트(30문항) | 의도 문항 3개, 그래픽 2세트는 **마지막 2세트**, talkType 고르게 |
| 5 | 30문항 | vocab 9, pos 7, prep-conj 5, verb 4~5, pronoun 2, relative 1~2, comparison 1 |
| 6 | 4지문(16문항) | 지문마다 sentence 1. passageType: email 2, 나머지 2는 memo·notice·article·advertisement 중 |
| 7 | 15세트(54문항) | 2문항 세트 4 → 3문항 3 → 4문항 3 → 이중 2 → 삼중 3 순. text 1(2문항), chat 1(4문항), insertion 2(4문항 세트 마지막), synonym 2~4 |
- 파트 안 순서는 쉬움 → 어려움(Part 2·5는 섞어도 됨). 정답 위치는 회차·파트별 A~D 각 20~30%(Part 2는 A~C 각 27~40%), 같은 기호 4연속 금지.
