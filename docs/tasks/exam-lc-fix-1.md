# Part 3·4 문제 수정 1차 (8차 리뷰 반영)

먼저 `docs/reviews/review-8-exam-lc.md`를 끝까지 읽는다. **자기 원본 파일(docs/questions/pX-N.json)만 수정**한다. 병합본 questions/*.json은 총괄이 다시 만든다(직접 수정 금지). app.js 등 코드 파일 수정 금지, 커밋 금지.
병합 id ↔ 원본: p3-001~026 = p3-1 순서 1~26, p3-027~052 = p3-2, p4-001~020 = p4-1, p4-021~040 = p4-2 (예: p3-041 = p3-2-015). 리뷰 표에 원 id도 적혀 있다.

## 할 일 (리뷰의 데이터 항목 1·2·3·5·6 중 자기 파일 해당분 전부)
1. 난이도 2·3 정답이 대본 단어를 그대로 쓰는 문항 → 바꿔 말한 보기로 교체(리뷰 제안값 참고, 더 나은 표현이면 그걸로). 표에 없는 것도 자기 파일 전체를 한 번 더 찾아서 고친다(정답 보기와 대본의 내용어 명사·동사 겹침).
2. 그래픽 문항: 리뷰 지적 수정 + 보기를 **표 순서대로** 정렬하고 answer 재지정.
3. 의도 문항: 인용문 바로 뒤에 뜻을 풀어 주는 대사가 있으면 그 풀이를 없애거나 간접적으로 바꿔 맥락으로만 정해지게.
4. 약한 오답·구조 반복·대본 논리·영어·번역·해설 오류: 리뷰 표의 자기 파일 항목 전부.
5. 대본을 바꾸면 scriptKo도 같이, explain·ko도 맞게. 인용문(의도 문항)은 대본에 그대로 있어야 함.

## 유지할 것
세트 수, 난이도 개수, talkType 개수, 그래픽·3인·의도 개수, 대본 길이(Part 3 90~150, Part 4 100~160단어), 정답 위치 A~D 각 20~30%(정렬로 깨지면 다른 문항 보기 순서로 맞추기).
