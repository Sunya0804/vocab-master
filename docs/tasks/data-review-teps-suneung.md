# 데이터 표본 리뷰: TEPS 2000 + 수능 3000 (Codex, 읽기 전용)

packages/teps.json, packages/suneung.json 을 **수정하지 말고** 검토만. 결과는 파일로 저장.
형식 검증(5칸·중복·품사 약어·levels 합)은 총괄이 이미 통과 확인함. 이번엔 **내용 정확도**.

## 방법 (패키지별)
- 레벨별로 고르게 무작위 표본: TEPS 100개, 수능 150개.
- 항목마다 판정:
  1. 뜻(ko)이 영단어의 대표 뜻으로 맞는가
  2. 품사(pos)가 뜻과 맞는가
  3. 예문(ex)이 자연스러운 영어이고 해당 단어(또는 활용형)를 바른 의미로 쓰는가, 15단어 이내인가
  4. 해석(exKo)이 예문과 일치하는가
  5. 레벨이 대략 타당한가 (2단계 이상 어긋나면 표시)
- 전체 파일 대상 자동 점검도: 예문에 단어(앞 4글자 또는 불규칙형)가 없는 항목 목록, 예문이 서로 거의 같은 템플릿 반복 비율, 출판사 예문 그대로 복사 의심(docs/teps-sources.json, docs/suneung-sources.json 참고).

## 출력
- `docs/reviews/teps-review.md`, `docs/reviews/suneung-review.md`
- 각 파일: 표본 오류율(항목별), 오류 목록(단어/필드/현재/제안 수정값), 자동 점검 결과, 최종 판정(등록 가능 / 수정 후 등록 / 재작업).
- 오류 목록은 OpenCode가 그대로 적용할 수 있게 표 형식으로.
보고: 두 판정 + 오류율 요약.
