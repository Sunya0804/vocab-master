# UI 21차: 폴더블(갤럭시 Z 폴드 8 / 8 Ultra 등) 대화면 사용성 (UI 워커)

사용자: "폴드 8 ultra, 폴드 8 등 대화면에서의 사용성도 개선해줄래?"
공유 main 최신(bab83fe 이후)에서 시작. 데이터 수정·커밋 금지. ui-20의 넓은 화면(≥1024px 사이드바) 규칙은 유지하고 그 아래 구간을 채운다.

## 기기 기준(CSS px, 대략)
- 접은 화면(커버): 폭 약 360~420 — 지금 휴대폰 배치 그대로.
- 펼친 화면(안쪽): 세로 약 820~900 × 750~1000, 가로로 돌리면 약 1000~1100 × 820. 거의 정사각형.
- 접고 펴는 순간 창 크기가 바뀐다(새로고침 없이 배치가 따라가야 함).

## 할 일
1. **중간 구간(약 700~1023px) 배치 추가**: 홈 Day 목록 2열, 단어 목록·오답노트 2열 카드, 카드·퀴즈·빈칸·듣기·Part 1~5는 본문 폭 640~720px 가운데, 버튼·보기 터치 영역 넉넉히(높이 48px 이상). 메뉴는 하단 바를 폭에 맞게 가운데 정렬(늘어나지 않게) 또는 왼쪽 레일 — 하나 골라 일관되게.
2. **Part 6·7·모의 RC 2단**: 지금 ≥900px 기준이면 펼친 폴드 세로(약 840px)에서도 지문/문항 2단이 되도록 기준을 약 760px로 내리고, 2단일 때 각 칸 최소 폭·글자 크기 확인. 정사각형 화면에서 지문 칸 높이(하단 메뉴 제외) 맞춤.
3. **Part 1 사진**: 넓고 낮은 화면에서 사진이 너무 커져 보기 버튼이 화면 밖으로 밀리지 않게(사진 최대 높이 제한).
4. **접기/펴기**: resize·orientationchange에서 진행 중인 화면(카드·퀴즈·모의고사 타이머·듣기 재생)이 끊기거나 다시 그려지며 상태를 잃지 않는지. 필요하면 CSS만으로 처리.
5. **힌지(접히는 부분)**: `@media (horizontal-viewport-segments: 2)` / `(vertical-viewport-segments: 2)`를 지원하는 브라우저에서 2단 화면의 경계를 힌지 위치(env(viewport-segment-*))에 맞춘다(지원 안 하면 무시).
6. 글자 크기: 대화면에서 본문 16~18px, 영어 표제어·예문이 너무 작아 보이지 않게.
