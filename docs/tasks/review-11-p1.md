# 검토 11차: Part 1 사진 문제 전수 검토 (Codex 검토자)

대상: `questions/toeic-part1.json`(60문항)과 각 `image`(images/part1/*.webp). 사진을 하나씩 직접 열어 본다.
기준: `docs/tasks/exam-p167-spec.md` Part 1 부분, `docs/research/toeic-p1-p6-p7.md` 1장.

## 볼 것
1. 사진만 보고 정답이 하나로 확정되는가(다른 보기도 맞거나 정답이 사진과 안 맞으면 **필수**).
2. 사진 품질: 손·얼굴 왜곡, 글자·로고, 카메라 응시, 그림 같은 질감.
3. 번역·해설 오류.
4. 난이도 표시가 실제와 크게 다른 것.

## 방법
파일 수정·커밋 금지. 결과는 `docs/reviews/review-11-p1.md`에 문항 id·심각도(필수/권장/참고)·근거·고칠 방법(사진 재생성이 필요하면 표시). 끝나면 요약 보고.
