# 기능 C — 단어 검색 · 학습 통계 · 받아쓰기 · 독일어 발음

먼저 `docs/tasks/feat-common.md`를 읽는다. 트랙 이름 `c`(worktree `C:/Users/정우진/Documents/vm-wt/c`, 브랜치 `feat/c`). 새 화면은 새 파일(`js/search.js`, `js/stats.js` 등)로 만들고 `app.js`에는 라우트 몇 줄만 더한다.

## 1. 전체 단어 검색 (`#/search`)
- 모든 기본·가져온 단어장에서 단어·뜻·예문을 검색. 입력하는 동안 결과 갱신, 결과마다 단어장 이름과 Day를 보여 주고 누르면 그 Day로 이동.
- 단어장은 지연 로딩이므로 검색할 때 필요한 단어장을 불러온다(오프라인이면 캐시된 것만, 안내 문구).
- 홈·상단에 검색 진입점. 대소문자·독일어 움라우트(ä→a 등)·관사(der/die/das) 무시 매칭.

## 2. 학습 통계 (`#/stats`)
- 단어장별 진행률(학습한 Day / 전체, 아는 단어 수), 오답노트 수, 연습문제 파트별 정답률, 모의고사 회차별 점수 추이(LC·RC·합계 선 그래프, 외부 라이브러리 없이 SVG).
- 기록이 없을 때의 빈 화면 문구.

## 3. 받아쓰기 모드
- Day 학습 모드(카드·빈칸·퀴즈와 같은 자리)에 "받아쓰기" 추가: 단어(또는 예문) 발음을 듣고 철자를 입력, 채점 후 정답·뜻 표시, 틀린 단어는 오답노트에. 기존 빈칸 입력의 채점 규칙(대소문자·독일어 키보드 설정)을 재사용한다.
