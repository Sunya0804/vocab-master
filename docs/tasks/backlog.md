# 나중에 할 개선사항

app.js 분리(split-app.md) 뒤에 해당 파일만 고치는 작업으로 진행.

## 화면·기능
- 예문 빈칸: 독일어 분리동사 매칭(anfangen → "fängt … an"처럼 떨어진 형태도 빈칸으로). 사용자: "그것도 나중에 개선사항으로 넣자."
- 독일어 발음: speak()가 utterance.voice를 직접 고르지 않음 → 듣기 모드처럼 speechVoice로 선택. 기기에 독일어 음성이 없으면 한 번 안내.
- 독일어 발음: "ihr / Ihr", "Deutsch / deutsch" 같은 빗금 표기는 소리로 읽을 때 앞 단어만.
- Part 3·4: 화자 음성이 성별과 무관하게 배정됨(review-8 4번, 분리 전 app.js:765-767).
- 실전 모의고사(LC/RC 전체, 타이머) — 사용자: "나중에는 실전문제도 만들자." → 진행 중: Part 1·6·7 추가 후 **5회분**, 기존 문제 조합 금지·전부 새 문제(사용자: "실전 모의고사는 5회 분량을 만들자"). 분석: docs/tasks/toeic-analysis-p1-p6-p7.md

## 확인 못 한 것
- 휴대폰 실기기: Part 2·3·4 음성, 예문 빈칸 입력(자동 대문자·자동 수정 꺼짐, 독일어 키보드), 독일어 발음.

## 데이터 부채
