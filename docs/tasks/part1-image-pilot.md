# Part 1 사진 시범 제작 (Codex)

사용자: "파트 1을 포함해서 … 난이도와 유형 및 그림이 최대한 유사하도록 구현해줘."
목적: 실제 토익 Part 1처럼 보이는 **새 사진(직접 생성)** 을 만들 수 있는지, 어떤 방법·용량·품질이 되는지 시범. 대량 제작 전 확인용. 코드·기존 데이터 수정 금지, 커밋 금지.

## 할 일
1. 쓸 수 있는 이미지 생성 수단을 확인(내장 이미지 생성, 사용 가능한 API 등). 없으면 바로 그 사실만 보고하고 멈춘다.
2. 실제 Part 1 사진 특징: 실사 사진 느낌, 자연광/실내 조명, 인물이 일상 업무 동작 중(서류 정리, 상자 운반, 계산대, 공사, 식당 테이블 정리 등), 얼굴 클로즈업 아님, 글자·로고 없음, 배경에 사물 여러 개(오답 함정 재료). 실존 인물·브랜드·저작물 모사 금지, 기존 시험 사진 따라 그리기 금지.
3. 시범 3장: ① 1인 동작(실내 사무실) ② 2인 이상(야외/상점) ③ 사람 없는 사물·풍경("is being" 함정용, 예: 쌓인 의자, 정박한 배).
4. 저장: `docs/pilot/part1/p1-pilot-1.webp` 등. 가로 1024px 이하, webp, 장당 120KB 이하로 압축(필요하면 python Pillow 등 사용).
5. 각 사진마다 Part 1 문항 1개 초안: 보기 4개(A~D 문장, 정답 1), 정답 근거, 오답 함정 종류. JSON: `{"id","image","alt","choices":[...4],"answer","ko":{"choices":[...]},"trap":[...],"explain"}`. alt는 스크린리더용 사진 설명(한국어, 정답을 그대로 말하지 않게).

## 보고
사용한 생성 수단, 장당 걸린 시간·용량, 사진이 실제 시험과 비슷한 점·다른 점(솔직하게), 사진 속 손·글자 깨짐 같은 결함 유무, 50장 이상 만들 때 예상 문제.
