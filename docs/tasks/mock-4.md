# 실전 모의고사 16~20회 (Claude 작성자 3명)

사용자: "실전 문제 문항수 추가 작업을 하자." 1~15회와 같은 방식으로 **16~20회(5회분, 1000문항)를 전부 새로** 쓴다.

## 규칙
- 명세: `docs/tasks/mock-spec.md`(1회 구성·순서 규칙) + `docs/tasks/exam-p167-spec.md` 끝 "검토에서 나온 규칙" **전부**(crossRef 3단계 검증, 회차 간 다른 배치, 그래픽·의도 위치 분산, Part 6 16번 대입, 정답 위치 순열 금지, tense 공식 금지 등).
- 형식은 같은 파트의 `-3` 파일(11~15회)을 그대로 따른다(필드·id·test 값). id는 `m-p3-16-05` 형식, `test` 값은 16~20.
- **기존 연습 문제(`questions/*.json`, `docs/questions/*.json`)와 모의 1~15회(`docs/mock/*.json`)와 소재·상황·문장·사진 장면·회사 이름이 겹치지 않게.** 쓰기 전에 같은 파트 기존 파일의 제목·첫 문장·회사 이름을 훑는다.
- 검토 31~35차(`docs/reviews/review-31*.md`~`review-35*.md`)에서 반복 지적된 것을 피한다: 부정 사실로 오답 지우기, "보는 사람이 도착했을 때 진행 중" tense 틀, 상식만으로 지워지는 오답, 같은 흐름 3세트 이상, 정답 위치 순열.
- 회차 하나 끝날 때마다 저장(한도로 멈춰도 저장분은 남게). **자기 파일만** 고친다. 커밋 금지.
- 다 쓰면 스스로 한 번 전수 재풀이(정답 하나인지, 해설·번역 일치)를 하고 고친 뒤 보고한다.
