# 토익 다의어 2단계: 나머지 370단어 예문 (OpenCode)

1단계(`docs/tasks/toeic-senses-1.md`) 시범 30개는 총괄 검사에서 수정 필요 2개(7%)로 통과했다. 같은 규칙으로 나머지를 쓴다.
**packages/toeic.json은 읽기만.** 결과는 `docs/senses/` 새 파일로만. 코드 수정·커밋 금지.

## 할 일
- `docs/senses/candidates.json`의 31~400번째 단어(370개), senses 각 뜻마다 예문 1개.
- 출력: `docs/senses/draft-2.json` = `[{"index","en","sense","pos","ex","exKo"}]`. **`sense`는 이 예문이 보여 주는 뜻 하나**(예: "예약하다"). 1단계 30개도 같은 형식으로 `docs/senses/draft-1b.json`에 sense를 채워 다시 저장.
- 50단어마다 저장.

## 규칙 (1단계와 같음 + 시범에서 나온 것)
- 토익 업무·생활 상황, 12~20단어, 그 뜻이 문맥으로 분명할 것, 표제어(또는 활용형)가 문장에 그대로.
- exKo는 해라체(~다). 어색한 직역 금지(시범의 deposit "맡겨야" → "입금해야" 같은 것).
- 기존 ex와 **다른 뜻**이어야 함(시범의 yield처럼 기존 예문과 같은 뜻이면 안 됨).
- 틀에 단어만 바꿔 끼우기 금지, 출판사 예문 복사 금지.

## 끝나면
개수, 무작위 10개 보고.
