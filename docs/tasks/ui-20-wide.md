# UI 20차: PC 넓은 화면 (UI 워커)

공유 main 최신(aa11ed7)에서 시작, 데이터 수정·커밋 금지.
지금 PC에서 앱 전체가 휴대폰 폭(480px) 가운데 좁은 칸이다(Part 6·7·모의 RC만 2단). 넓은 화면(≥1024px)에서:
- 홈: Day 목록을 2~3열 격자로, 단어장·레벨 선택은 위쪽 한 줄.
- Day 단어 목록·오답노트: 2열 카드.
- 카드·퀴즈·빈칸·듣기·Part 1~5 문제: 가독성을 위해 본문 폭은 640~720px 정도로 가운데 정렬(너무 넓지 않게).
- 하단 메뉴: 넓은 화면에서는 왼쪽 세로 메뉴(사이드바) 또는 상단 메뉴로. 휴대폰(<768px)은 지금 그대로.
- 다크 모드·포커스 표시 유지.
검증: node test/*.test.js, Playwright 390·768·1280·1600px 라이트·다크 주요 화면, 콘솔 에러 0, 가로 스크롤 없음. sw.js CACHE_VERSION 올림. 끝나면 바꾼 파일·스크린샷 경로 보고.
