# UI 19차: 밀린 화면 개선 (UI 워커)

공유 main 최신(ccb7467)에서 시작, 데이터 수정·커밋 금지.
1. 언어 전환(영어/독일어)이 마지막으로 보던 단어장을 언어별로 기억(지금은 그 언어 첫 단어장).
2. 언어·레벨 칩: 눌린 상태에서 마우스를 올리면 모양이 어색한 것(눌림/올림 스타일 충돌) 정리.
3. 듣기 모드에서 다의어(6번째 칸) 예문도 원하면 읽기 — 설정 토글 없이, 기본 예문 뒤에 "다른 뜻" 예문을 이어 읽는 정도로 최소 구현. 너무 길어지면 첫 번째 다른 뜻만.
4. 모의고사 결과 화면·RC 화면을 실데이터(`questions/mock/mock-1.json`)로 끝까지 풀어 보며 어색한 곳(긴 Part 7 지문 스크롤, 답안지 닫기, 타이머 표시) 고치기.
