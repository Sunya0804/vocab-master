# 코어 수정: parseImport 쉼표 회귀 (재리뷰 높음)

담당 파일: core.js, test/core.test.js 만. 다른 파일 수정 금지 (UI/데이터 워커가 동시 작업 중).
먼저 SPEC.md의 core.js 인터페이스 절, 특히 "parseImport 구분 규칙 확정" 줄을 읽을 것.

## 버그
탭이 없는 줄에서 parseImport가 모든 쉼표로 나눔 (core.js:120-129 부근 splitFields).
`accommodate, 수용하다, 숙박시키다` 가 `["accommodate","수용하다","숙박시키다"]` 가 되어 뜻이 잘리고 "숙박시키다"가 품사 칸에 들어감.

## 수정 규칙
- 줄에 탭이 있으면 탭으로 최대 5칸. 따옴표로 감싼 칸은 따옴표 제거, 따옴표 안의 탭/쉼표 보존.
- 탭이 없으면 따옴표 밖 첫 번째 쉼표에서만 2칸 분리: `["accommodate","수용하다, 숙박시키다"]`.
- 구분자 없는 "word 뜻" 공백 규칙은 기존대로.

## 테스트
- test/core.test.js:82 부근 기존 쉼표 테스트를 위 규칙에 맞게 수정.
- 추가: 따옴표 없는 `en, 뜻1, 뜻2` / 탭 5칸(예문에 쉼표 포함) / 따옴표 안 쉼표 케이스.
- 다른 기존 테스트는 유지·통과.

## 완료 기준
`node test/core.test.js` 전부 통과. 변경 요약 + 테스트 출력 끝부분 보고.
